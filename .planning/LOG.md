## 2026-08-18 (MLS dedupe investigation)

**Phase:** None — investigatory deviation, no phase file active. Sole output: updated `data/raw/mls/data-notes.md`. No R scripts written or modified; no pipeline changes.

**Purpose.** The pending MLS cleaning pipeline uses PID+Sales Date as its primary cross-MLS dedupe key. This session investigated whether that key produces false positives before the R pipeline is built, specifically checking whether PIDs shared across condo units or subdivided lots could mis-flag genuinely distinct sales as duplicates.

**Finding: PID+date is safe.** A Python investigation across all 80 CVR export files (110,450 rows, 1,098 cross-MLS pairs) found no false positives from multi-unit or multi-lot PID sharing. The 89 PID-only pairs (caught by PID+date but not by addr+date+price) break down into four mechanical categories: (1) street type abbreviated differently between CVR and REIN/BRT ("Uplands Dr." vs "Uplands Drive"), (2) identical normalized addresses with a small price difference (exact-price key fails on a $2 rounding gap), (3) REIN addresses that retain a "VA 23xxx" suffix when the city is omitted from the source — the city-strip regex requires a `, City VA` pattern and fails silently — and (4) address-less REIN records already documented. Every pair in the sample had the same street number on both sides.

**One required normalization fix.** 483 rows carry `PID = "Not Yet Assigned"`. Stripping hyphens and spaces before checking the placeholder list turns this into `NOTYETASSIGNED`, which escapes exclusion and joins unrelated records sharing a sale date (3 confirmed false pairs in the data, all from new-construction subdivisions in New Kent where parcels had not yet been assigned). All 3 false pairs fail the price/sqft tolerance and route to the manual-review file anyway, but the fix eliminates them cleanly: check the exclusion list on the raw string before stripping.

**Two structural REIN patterns documented.** REIN sale prices can diverge substantially from CVR on the same closing (up to $77k observed, with identical list price — likely a different transaction stage captured). REIN sqft often reflects total building area; CVR reflects finished living area. Neither pattern indicates a different property.

**Three outside-tolerance pairs confirmed by manual MLS lookup.** 7991 Uplands Dr (CVR 2128471 / REIN REIN10401157): same listing, $77k sale-price gap is a transaction-stage artifact, keep CVR. 10797 Providence Woods Lane (CVR 2209684 / REIN BRTVAHA2000158): REIN sale price $335,000 is a dropped-digit typo for $435,000, keep CVR. 3121 Ponderosa Pine Ln (CVR 202500335 / REIN REIN10611370): sqft difference is finished vs total area, keep CVR. All three dispositions and both structural patterns added to `data/raw/mls/data-notes.md`.

**No 2022 baseline metrics.** This session touches no data scripts and produces no analysis outputs.

**Left open.** The R cleaning pipeline (`r/mls.R` transaction-level build) is not yet written — that is Phase 3 scope. The NOTYETASSIGNED fix needs to be implemented in R at pipeline-build time.
